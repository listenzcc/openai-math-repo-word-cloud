五、分析与制图方法

语料

  • 目录名：preprints/ 下每篇手稿的目录名（含标题式命名）
  • README.md：每篇手稿的自述文件
  • CONTENTS.md：问题族索引，提供学科分类标签

分析

  • 分词后过滤停用词（the / of / a / proof 等无区分度词）
  • 小写归一、去连字符变体、合并简单单复数
  • 按学科标签聚合，得到分维度词频

制图

  • 离线 Python 脚本产出 data/words.json 与 data/graph.json
  • 词云：wordcloud2.js 渲染，字号线性映射词频
  • 关系图：D3 force 力导向布局，按问题族连边
  • 纯静态、零构建，直接挂 GitHub Pages

边界

  • 只统计目录名与 README，未读正文 PDF
  • 仓库收录 ≠ 结果经过同行评审；部分结果尚未 Lean 形式化
  • 数据截至本次 clone 时的仓库快照
